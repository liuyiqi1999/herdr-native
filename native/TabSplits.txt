Herdr Native — plain UI and built-in splitting

Only Herdr's built-in pane splitting is supported.
Cmd+D splits right; Cmd+Shift+D splits down. Pane context-menu splits,
focus, resize, zoom and close use the upstream Herdr implementation.

Removed: custom native tab groups, four-way tab splitting, cross-surface
tab drag/drop, tab ownership files, split chord timers, workspace host
layout caching, move-tab-right helper, and Liquid Glass presentation.
Upstream tab reordering and pane-divider dragging remain unchanged.
The client uses standard TUI chrome. Completed unread tabs flash their
background in both the top strip and sidebar, stopping when marked read.
The Ghostty notification patch lets Herdr's already-filtered background-tab
notifications appear even while the outer surface is focused, and waits for
notification authorization before sending. macOS notification permission is
still required.

Build (legacy build script/worktree names retained):
  cd herdr-worktrees/tab-groups
  ZIG="$PWD/../../.tools/zig/ziglang/zig" CARGO_TARGET_DIR=../../herdr/target CARGO_PROFILE_RELEASE_OPT_LEVEL=1 cargo build --release --locked
  cd ../../ghostty
  macos/build.nu --configuration ReleaseLocal --action build
  cd ..
  python3 scripts/build_tab_groups.py --ghostty-app ghostty/macos/build/ReleaseLocal/Ghostty.app --output 'dist/Herdr Native Plain.app'

Regression smoke (use --test when packaging):
  HERDR_TEST_APP="$PWD/dist/Herdr Native Plain Test.app" python3 scripts/smoke_builtin_splits.py
Checks both split shortcuts create backend panes in the same tab, without
creating additional Ghostty surfaces/clients. Checks existing terminal IDs,
new-tab creation, absence of glass resources and stale environment isolation.

The Herdr patch includes the completion-flash regression tests and an ignored
fixed-geometry scaling profile. It is a complete patch, not an incremental
patch to stack on the earlier built-in-splits patch.

The packaging script uses /Applications/Herdr Native.app as its bundle template
and the legacy herdr-worktrees/tab-groups checkout as its source-patch input.
Older complete patches and patches under archived-builds are historical, not
the current build.

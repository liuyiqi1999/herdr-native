Herdr Native — native Liquid Glass presentation

Implementation
- ghostty/macos/Sources/Features/Terminal/HerdrGlassBackdrop.swift:
  macOS 26 SwiftUI glassEffect per tab capsule, tab bar, sidebar section and pane.
  NSVisualEffectView fallback on older systems; opaque material when Reduce
  Transparency is enabled. Borders respect increased contrast.
- herdr-worktrees/tab-groups/src/client/shell/native_glass.rs:
  client-only, versioned geometry mailbox, keyed by native surface UUID.
  Runs at most 4 Hz outside render; writes atomically only when layout changes.
  No server protocol changes. Works before local/remote ownership filtering.
- Glass is behind Metal, ignores hit testing and accessibility. Existing TUI
  text, controls, keyboard handling and native tab-group drag routing remain.
  This is a native material presentation layer, not a rewrite of controls as
  SwiftUI buttons/lists. Glass builds use taller tab capsules with full-height
  hit targets and readable foreground text. Single-pane cards fill the native
  canvas even while the shared backend negotiates a narrower viewport.
- native/native-glass.conf enables cell transparency, a dark Rex-like palette,
  transparent titlebar and zero grid padding. Non-glass builds stay unchanged.
- Launch with HERDR_NATIVE_GLASS=0 to disable both bridge and extra config.

Build from /Users/bytedance/Code/herdr-native
1. Build the tab-groups client with Zig 0.16.0:
   cd herdr-worktrees/tab-groups
   ZIG="$PWD/../../.tools/zig/ziglang/zig" CARGO_PROFILE_RELEASE_OPT_LEVEL=1 cargo build --release --locked
   cd ../..
2. Build the Ghostty core using its required Zig version, then:
   nu ghostty/macos/build.nu --configuration ReleaseLocal
3. Package without touching /Applications:
   python3 scripts/build_tab_groups.py --glass --test \
     --herdr herdr-worktrees/tab-groups/target/release/herdr \
     --ghostty-app ghostty/macos/build/ReleaseLocal/Ghostty.app \
     --output "dist/Herdr Native Glass Test.app"
